# EssayScorer Frontend

Run from this folder:

```bash
npm install
npm run dev
```

The browser app talks to FastAPI at `http://127.0.0.1:8000` by default. You can override it with `VITE_API_URL`.

Modules included: Dashboard, New Essay, Analysis, History, Documents, Writing Quiz, My Reports, Writing Coach, Settings, Login/Register/Forgot/Reset Password.
