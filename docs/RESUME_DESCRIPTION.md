## Resume Project

### AI-Based Automated Essay Scoring & Intelligent Writing Analytics Platform
**Tech:** Python, NLP, Scikit-learn, Linear Regression, TF-IDF, FastAPI, React.js, SQLite, ReportLab

- Developed an NLP-based essay evaluation platform combining TF-IDF and engineered linguistic features with Linear Regression for automated score prediction.
- Built a FastAPI REST backend and React dashboard supporting essay evaluation, writing analytics, history, topic-relevance signals and professional PDF reports.
- Implemented rule-based natural-writing improvement suggestions covering repetitive wording, sentence variety, clarity and transitions.
- Evaluated model performance using RMSE, MAE and R² and added automated API smoke tests plus an end-to-end deployment workflow.
